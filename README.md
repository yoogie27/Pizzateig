# Pizza Teig Master Calculator

https://yoogie27.github.io/Pizzateig/

Berechnet Zutaten, Zeitplan und Sauce fuer perfekten Pizzateig - von Poolish ueber Biga bis Sauerteig.

## Features

- **7 Teigarten:** Poolish, Biga, Roemisch, Schnell, Croccante, Sauerteig, Griessteig
- **Automatischer Zeitplan:** Rueckwaerts gerechnet ab Verzehrzeit
- **Startzeit-Option:** Eigene Startzeit angeben - Hefe wird automatisch an die verfuegbare Zeit angepasst
- **Temperaturanpassung:** Hefemenge reagiert auf Raumtemperatur (besonders relevant bei Biga)
- **Olivenoel-Toggle:** Optional fuer jeden Teig zuschaltbar
- **Saucenrezept:** NY/Roma Style, skaliert mit Pizzaanzahl
- **Belag-Guide:** Kaese-Guide, Schichtungsregeln und 12 Klassiker-Pizzen mit konkreten Belegtipps

## Rezept teilen

Alle Einstellungen werden in der URL gespeichert. Einfach das Rezept konfigurieren und den Link verschicken - der Empfaenger sieht exakt deine Konfiguration (Teigtyp, Anzahl, Gewicht, Zeitpunkt, Olivenoel etc.).
